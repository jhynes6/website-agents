# DigitalOcean Gradient™ AI Platform

Generated on 22 Dec 2025

DigitalOcean Gradient™ AI Platform lets you build fully-managed AI agents with knowledge bases for retrieval-augmented generation, multi-agent routing, guardrails, and more, or use serverless inference to make direct requests to popular foundation models.

## Latest Updates

### 18 December 2025

- The following models are now available on DigitalOcean Gradient™ AI Platform for [serverless inference](https://docs.digitalocean.com/products/gradient-ai-platform/how-to/use-serverless-inference/) and [Agent Development Kit](https://docs.digitalocean.com/products/gradient-ai-platform/how-to/build-agents-using-adk/):


  - [Claude Opus 4.5](https://www.anthropic.com/news/claude-opus-4-5)

  - [Claude Opus 4.1](https://www.anthropic.com/news/claude-opus-4-1)

  - [Claude Sonnet 4.5](https://www.anthropic.com/news/claude-sonnet-4-5)


For more information, see the [Available Models page](https://docs.digitalocean.com/products/gradient-ai-platform/details/models/).

### 17 December 2025

- Knowledge base chunking and retrieval are now in [public preview](https://docs.digitalocean.com/platform/product-lifecycle/#public-preview). Chunking splits your documents into smaller units before indexing, and existing data sources default to section-based chunking.

You can update chunking settings in the [control panel](https://docs.digitalocean.com/products/gradient-ai-platform/how-to/create-manage-agent-knowledge-bases/#create-control) or [via the API](https://docs.digitalocean.com/products/gradient-ai-platform/how-to/create-manage-agent-knowledge-bases/#create-api), and retrieve recent chunks using the [retrieval endpoint](https://docs.digitalocean.com/products/gradient-ai-platform/how-to/create-manage-agent-knowledge-bases/#retrieve-api). For more details, see the [API reference](https://docs.digitalocean.com/products/gradient-ai-platform/reference/chunking-strategies/) and [chunking best practices](https://docs.digitalocean.com/products/gradient-ai-platform/reference/chunking-strategies/).


### 11 December 2025

- Gradient AI Platform also now supports the Qwen3 Embedding 0.6B (Multilingual) model from [Alibaba Qwen](https://github.com/QwenLM) in public preview. Select this model for multilingual indexing workflows. Learn more on the [embedding models](https://docs.digitalocean.com/products/gradient-ai-platform/details/models/#embedding-models) page.


For more information, see [all Gradient AI Platform release notes](https://docs.digitalocean.com/release-notes/gradient-ai-platform/).
